# FotoDex

FotoDex es una aplicación web móvil instalable (PWA) para fotografiar animales, crear una colección y compartir observaciones.

## Estado actual

Esta primera versión es una maqueta interactiva local. Incluye navegación móvil, feed de ejemplo, colección y filtros, perfil, y selección de cámara o galería. Las imágenes seleccionadas se convierten en JPEG de hasta 1800 px con calidad 84 antes de procesarse.

La identificación con IA, cuentas de usuario, almacenamiento remoto, ubicación, comentarios y sincronización social requieren conectar un backend. Los datos y animales de ejemplo no son contenido real.

## Abrir en el navegador

Sirve esta carpeta con cualquier servidor web local para que funcione el modo instalable. El acceso a cámara y galería requiere permiso del navegador. El Service Worker guarda los archivos de la app para uso posterior.
